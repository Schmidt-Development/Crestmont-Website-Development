## 3. Malware scanning for files uploaded to Cloudflare R2

Volume assumption: a few hundred files per month, mostly client documents and images, from authenticated portal users.

**Reference architecture (applies to every option):** Upload goes through the Worker to an R2 **`quarantine/`** prefix. An R2 event notification (`object-create`) goes to a **Cloudflare Queue**, and a consumer Worker sends the object to the scanner. The verdict comes back: clean files are moved to `files/` and marked downloadable, while infected or errored files are kept in quarantine (or deleted) and an alert goes out. The portal must refuse downloads of any object not marked clean (**fail closed**). R2 event notifications support `object-create` and deliver to a Queue consumed by a Worker or by HTTP pull. Queues are available on Workers Free with 10,000 ops/day included; Paid includes 1M ops/month, then $0.40 per million.
Sources: https://developers.cloudflare.com/r2/buckets/event-notifications/ ; https://developers.cloudflare.com/queues/platform/pricing/

### Recommendation (default for a tiny company with no budget approval)

1. **Default: self-hosted ClamAV on the existing Docker runner, in pull mode from a Cloudflare Queue.** It costs $0, and client files never leave Crestmont-controlled systems, which matters because portal files are client confidential data under the DPA. Use the quarantine-prefix and fail-closed pattern so that if the runner is down, files simply stay "pending" rather than becoming downloadable unscanned. Give the runner an R2 API token scoped read and write to the bucket only, and have it send an HMAC-signed callback to the Worker.
2. **Defense in depth that costs nothing:** an allowlist of file extensions and MIME types (sniff magic bytes in the Worker), a size cap, rejection of encrypted archives, `Content-Disposition: attachment` and `X-Content-Type-Options: nosniff` on downloads, and never serving uploads from the main app origin.
3. **Fallback or upgrade:** If the runner proves unreliable, the **Cloudmersive free tier (600/mo)** works as a hosted backstop for small files once its DPA is reviewed. If commercial-engine detection is wanted later, **scanii Basic** ($49/mo, or $9.99 startup pricing on request) is the cheapest published paid option found. Moving ClamAV into **Cloudflare Containers** (Workers Paid $5/mo plus 4 GiB instance time) removes the dependency on the home runner.
4. **Do not use** the VirusTotal public API: its terms prohibit commercial use, and it can expose client files to third parties.
